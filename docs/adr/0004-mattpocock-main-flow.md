# The Matt Pocock main flow is the kit's canonical workflow

**Status: Superseded.** This record describes the flow the kit carried before the pstack port. `magic-mode` (ADR-0008) now owns entry-point routing and the playbook lifecycle, `/interrogate` and `/thermo-nuclear-code-quality-review` replace the review step, `/subagent-driven-development` replaces plan execution, and the retired `code-review` and `cr-*` suite is gone. The record below stays as history.

The owner's main flow was the Matt Pocock flow, which grills the idea (`/grill-with-docs`), specs it (`/to-spec`), splits tickets (`/to-tickets`), and implements test-first (`/implement` driving `/tdd`), and the kit was a set of add-ons around it, not its engine. The wrapper skills live outside this repo and were installed separately. The kit's two-tier `code-review` (ADR-0005) served the flow's review step, `/research` fed its grilling and spec steps, and `/triage` and `/wayfinder` handled incoming issues and oversized efforts. The skills were configured per repo by `setup-matt-pocock-skills` (tracker, labels, domain docs), which replaced the kit's own `setup-agent-kit` and `kit.json`, since those had no consumers left after the rework. The kit previously orchestrated its own flow through `ship` (Linear, plan-review, MR). The owner abandoned that pipeline because plan review didn't earn its keep, and adopted the interview-first flow wholesale.
