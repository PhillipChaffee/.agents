# The Matt Pocock main flow is the kit's canonical workflow

The kit exists to power one flow: grill the idea (`/grill-with-docs`), spec it (`/to-spec`), split tickets (`/to-tickets`), implement test-first (`/implement` driving `/tdd`), and close with the kit's two-tier `code-review` (ADR-0005), with `/triage` as the on-ramp for incoming issues and `/wayfinder` for efforts too large for one session. Those wrapper skills are Matt Pocock's and live outside this repo; the kit treats them as assumed environment, configured per repo by `setup-matt-pocock-skills` (tracker, labels, domain docs) — replacing the kit's own `setup-agent-kit` and `kit.json`, which had no consumers left after the rework. The kit previously orchestrated its own flow through `ship` (Linear → plan-review → MR); the owner abandoned that pipeline (plan review didn't earn its keep) and adopted the interview-first flow wholesale.
