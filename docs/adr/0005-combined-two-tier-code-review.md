# One combined two-tier code review

The kit previously carried two review engines: a multi-agent specialist pipeline (planner, eight domain reviewers, verifier, walkthrough, implementer) and a lightweight two-axis review (Standards + Spec). They covered gaps in each other — the specialist panel was wider per diff but never checked spec conformance, and the two-axis review caught "clean code implementing the wrong thing" but had no depth, false-positive filtering, or fix loop. Running both as separate skills also colliding on the `code-review` name made dispatch ambiguous. The kit now ships one `code-review` skill with tier triage: the standard tier runs the two-axis review, and the deep tier runs the two axes plus the planner-selected specialist panel and verifier, with walkthrough and opt-in fixes. The alternative — keeping both as separately named skills — preserved a collision and forced the user to know which to invoke; triage inside one skill makes the shallow path default and the deep path explicit.
