# The Matt Pocock main flow is the kit's canonical workflow

The owner's main flow is the Matt Pocock flow — grill the idea (`/grill-with-docs`), spec it (`/to-spec`), split tickets (`/to-tickets`), implement test-first (`/implement` driving `/tdd`) — and this kit is a set of add-ons around it, not its engine: the wrapper skills live outside this repo and are installed separately. The kit's two-tier `code-review` (ADR-0005) serves the flow's review step, `/research` feeds its grilling and spec steps, and `/triage` and `/wayfinder` handle incoming issues and oversized efforts. The skills are configured per repo by `setup-matt-pocock-skills` (tracker, labels, domain docs) — replacing the kit's own `setup-agent-kit` and `kit.json`, which had no consumers left after the rework. The kit previously orchestrated its own flow through `ship` (Linear → plan-review → MR); the owner abandoned that pipeline (plan review didn't earn its keep) and adopted the interview-first flow wholesale.
