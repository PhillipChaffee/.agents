# The kit self-lints with the reference repo's hygiene gates

This repo's own files run through the same repo-wide hygiene gates full-lint runs on itself: typos spell check, markdownlint, lychee link check, gitleaks secret scan, jscpd copy-paste detection, shellcheck and shfmt over tracked `.sh`, yamllint and actionlint over `.github/workflows`, plus Dependabot watching the SHA-pinned Actions. The configs are byte-for-byte copies of full-lint's (`.typos.toml`, `.markdownlint-cli2.jsonc`, `.jscpd.json`, `.gitleaks.toml`, `.yamllint.yaml`, `lychee.toml`, `.github/dependabot.yml`) and the gates run as a second `hygiene` job in `validate.yml` beside the kit-structure `validate` job; flagged content gets fixed, never the copies relaxed. The gates live outside kit content (`agents/`, `rules/`, `skills/`), so the installer never ships them to consumers. This does not amend ADR-0002's decision: hygiene tooling is language-agnostic and applies to this repo's own files, while the kit still carries no per-language rules — those stay in full-lint, applied per project by its `init-<lang>-repo` skills. Only the steps with nothing to check are dropped here (osv-scanner advisories and license checks, the Python lockfile-integrity gate), and the per-language `ci.yml`/`mutation.yml` glob targets reduce to `.github/workflows/*.yml`.
