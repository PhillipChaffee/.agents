# One combined two-tier code review

**Status: Superseded.** The pstack port (ADR-0008) removed the `code-review` skill and the whole `cr-*` suite. Review now runs through `magic-mode`'s playbooks, `/interrogate` for a cross-model review of the diff, `/thermo-nuclear-code-quality-review` for the deep maintainability audit, and `/subagent-driven-development` for the per-task review gate. The record below stays as history.

The kit previously carried two review engines, a multi-agent specialist pipeline (planner, eight domain reviewers, verifier, walkthrough, implementer) and a lightweight two-axis review (Standards and Spec). They covered gaps in each other. The specialist panel was wider per diff but never checked spec conformance, and the two-axis review caught "clean code implementing the wrong thing" but had no depth, false-positive filtering, or fix loop. Running both as separate skills also collided on the `code-review` name, which made dispatch ambiguous. The kit then shipped one `code-review` skill with tier triage, where the standard tier ran the two-axis review and the deep tier ran the two axes plus the planner-selected specialist panel and verifier, with walkthrough and opt-in fixes. The alternative of keeping both as separately named skills preserved a collision and forced the user to know which to invoke, so triage inside one skill made the shallow path default and the deep path explicit.
